02Nervous System Emulation — Cat-8 Array

The surrogate's nervous system is a Category 8 (Cat-8) copper topology configured exclusively for high-frequency 40GBASE-T. It maps data transmission directly against sub-millisecond sensory demands, isolating delicate compute from kinetic, magnetic, and thermal stress.

⚡

Throughput Ceiling

40 Gbps at a 2,000 MHz (2 GHz) bus width — matched to micro-sensory capture speeds with zero packet-queue buffering.

⏱️

Latency Control

Eliminates network-level serialization delays for spatial tracking, facial sync, and haptic telemetry without buffer interference.

🛡️

EMI Isolation

Strict S/FTP construction: foil-wrapped pairs inside an overall braided sleeve, blocking corruption from cooling pumps and high-draw logic.

Geometric Distance Containment

All interior runs are locked under 30 m (98 ft). Past that limit the link silently down-negotiates to 10 Gbps — the calculator below shows this live.

03Centralized Patch Panel Layout

To preserve space in the upper chassis and protect components from cable strain, every sensory connection is marshaled through a grounded, high-density 12-port mini-patch panel in the lower structural base frame. Ports 1–12 are the canonical base chassis; ports 13+ are reserved for research subsystems and the Human Twin.

043D-Printed Mini-Chassis Integration

The 10-inch form-factor mini-patch panel is housed in a custom enclosure integrated into the lower base frame, tailored for standard 3D-printing tolerances.

↔️

Slide-Out Rail Track

Dual-lip slide track lets the patch core slide fully outward for toolless access to rear keystone terminators during maintenance.

⬡

Hexagonal Ventilation

Algorithmic, non-deforming hexagonal lattice across the back wall optimizes plastic weight distribution and exhausts active 40GBASE-T NIC heat.

⚠️

ESD Grounding

Internal metal backing bar bonded to a 10AWG copper drain wire routes static straight to earth ground, protecting the i5 core and GPUs.

05PoE++ Power Delivery — IEEE 802.3bt

To avoid massive parallel DC wiring looms, power is layered entirely over the Cat-8 data lines using IEEE 802.3bt (PoE++ Type 4) — up to 90 W per line, with localized splitters dropping to clean 5 V / 12 V regulated rails at each sensory zone.

[PoE++ Injector / Switch in Base] ──(90W + 40 Gbps over S/FTP Cat-8)──▶ [Shielded Keystone] │ [Localized Terminal Splitter] / \ (40 Gbps Raw Data to Node) (DC Power to Actuators)

06Human Body · Mind · Nature Twin

The control plane extends into a structural digital twin of a full human: 11 anatomical body systems (15 organs), 10 cognitive mind modules, and a layer of human nature — each facet bound to a Cat-8 link on the research rig starting at port 13. The twin is ontology + state + telemetry + validation + raw-binary serialization — not a real-time simulation.

Body Systems & Organs 11 systems 15 organs

Cognitive Mind Modules 10 modules

Human Nature — Encoded into the Artificial Nervous System 38 constructs 5 groups

Human nature is encoded as a normalized weight (0.0–1.0) per construct and rides the same Cat-8 link layer as body and mind. The Instinct group is the survival / reflexive bedrock — the part of human nature wired directly as the surrogate's instinctual substrate (fight · flight · freeze · seeking · attachment · nurturance …). It is serialized as PROTO_NATURE frames, byte-compatible with the Rust core.

Raw Binary Link Layer

Every organ's vitals, every mind module's activation, and every nature construct's weight serialize into checksummed PROTO_BIOMETRIC / PROTO_COGNITIVE / PROTO_NATURE frames, byte-compatible between the Python and Rust cores (CRC32).

07Architecture & Extension

The framework is modeled as a small, typed, dependency-free Python control plane with a Rust core in parity. The design goal is extension, not implementation: R&D entities add sensor suites, power topologies, and chassis variants without forking core logic.

            ┌──────────────────────────────────────┐
            │            Surrogate                  │  surrogate.py
            │   orchestrates + health_check()       │
            └─────────┬────────────────┬────────────┘
         ┌────────────┴─────┐     ┌─────┴──────────────┐
         │   PatchPanel     │     │   PoeDelivery      │  patch_panel.py / poe.py
         │   (registry)     │     │   (per node)       │
         └────────┬─────────┘     └────────────────────┘
              ┌────┴─────┐
              │ Cat8Link │                                      cat8.py
              └──────────┘
         ┌─────────────────────────────────────────┐
         │   MiniChassis (ESD / vent / rail)        │  chassis.py
         └─────────────────────────────────────────┘
            telemetry.py → status/health    cli.py → new-body status|health|explore
  1. Register a subsystem — register_subsystem(SubsystemSpec(...)) at import time; ports 1–48, no overlap.
  2. Bespoke layout — PatchPanelBuilder().add(...).build(link_factory) for non-contiguous or simulated harnesses.
  3. New power topology — compose PoeDelivery/PoeSlice with different 5 V / 12 V rails, attach to Surrogate.poe.
  4. Instrumentation hook — replace render_status with a sink to a lab bus (MQTT / WebSocket / CSV); the telemetry dict is the contract.
  5. Visualize — new-body explore emits an interactive HTML topology generated from the live model.

Dual-language: Python is the primary API/CLI; Rust is the high-performance core (+ optional PyO3 bridge). When you change an extension point, keep both in parity.

09Glossary

Cat-8 / S/FTP

Category 8 shielded twisted pair: foil-wrapped pairs in a braided sleeve, rated 40GBASE-T to 30 m.

PoE++ (802.3bt Type 4)

Power over Ethernet delivering up to 90 W per line over the data cabling.

Patch Panel

The grounded 12-port base marshaling all subsystem links in the lower frame.

Mini-Chassis

3D-printed 10" enclosure with slide rail, hex vent, and ESD drain to earth.

Digital Twin

Structural model (ontology + state + telemetry + validation + serialization) of body & mind.

Link Layer Frame

Compact CRC32-checksummed binary frame carrying sensory/cognitive telemetry over Cat-8.
